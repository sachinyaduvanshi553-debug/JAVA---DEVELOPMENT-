# 🟦 Month 1: Java Fundamentals + DSA Patterns (Sep 4 → Sep 30)

> **Core Objective**: Master Java execution lifecycle, memory semantics, core syntax, and build foundational algorithmic pattern recognition (Hashing, Two Pointers, Sliding Window, Prefix Sum).

---

## ⏱️ Daily 3-Hour Time Allocation
* **Hour 1 — DSA (LeetCode)**: 2 Problems / day (Easy → Easy/Medium). Target: ~40 problems.
* **Hour 2 — Java Core**: Syntax, JVM compilation, memory model, methods, Strings & immutability.
* **Hour 3 — Engineering & Tools**: Git version control, Linux terminal CLI, Level-1 AI-assisted development.

---

## 📂 Submodules in this Section

### ☕ 1. [01-Java-Fundamentals](./01-Java-Fundamentals/)
* **`01-Language-Basics-JDK-JVM/`**: JDK vs JRE vs JVM, Bytecode verification, JIT compilation, Execution lifecycle, `public static void main(String[] args)`.
* **`02-Variables-DataTypes-Operators/`**: 8 Primitives, Reference types, Memory sizes, Widening & Narrowing Type Casting, Bitwise and Logical operators.
* **`03-Control-Flow-Conditionals-Loops/`**: Branching (`if/else`, switch expressions), Loops (`for`, enhanced `for`, `while`, `do-while`), Jump statements (`break`, `continue`, labels).
* **`04-Methods-Scope-Parameters/`**: Method signatures, Overloading, Scope, Call stack frames, Pass-by-value semantics, Recursion fundamentals.
* **`05-Strings-StringPool-Immutability/`**: String Pool (SCP), Immutability rationale, `StringBuilder` vs `StringBuffer`, Character arrays, Interning.

### 🧠 2. [02-DSA-Patterns-Hashing-TwoPointers-SlidingWindow](./02-DSA-Patterns-Hashing-TwoPointers-SlidingWindow/)
* **`01-Hashing-HashMap-HashSet/`**: Lookup optimization, frequency counting, duplicate tracking.
* **`02-String-Manipulation/`**: Anagram verification, Palindrome checks, ASCII manipulation.
* **`03-Two-Pointers-Sliding-Window/`**: Opposite ends, Fast & Slow pointers, Fixed vs Dynamic sliding windows.
* **`04-Prefix-Sum/`**: Range sum queries, Subarray sum equals K, Balance points.
