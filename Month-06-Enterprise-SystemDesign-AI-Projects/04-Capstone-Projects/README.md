# 🚀 3 Enterprise Capstone Projects

These 3 portfolio projects prove your abilities across Core Java, Backend, Distributed Systems, and AI Engineering:

---

## 📘 Project 1: Enterprise Java Backend API
* **Tech Stack**: Spring Boot 3, Java 21, PostgreSQL, Spring Security, JWT, Docker.
* **Key Features**:
  * Clean layered architecture (Controller $\rightarrow$ Service $\rightarrow$ Repository $\rightarrow$ Entity/DTO).
  * Stateless Authentication using JWT with refresh token rotation.
  * Role-Based Access Control (RBAC: Admin, Manager, User).
  * Full CRUD, pagination, filtering, search, and global exception handling.
  * 80%+ test coverage with JUnit 5 & Mockito.

---

## ⚡ Project 2: High-Throughput Scalable Distributed Backend
* **Tech Stack**: Spring Boot 3, PostgreSQL, Redis, Apache Kafka, Docker Compose.
* **Key Features**:
  * Multi-level caching (Redis Cache-aside pattern for hot data, TTL, invalidation).
  * Asynchronous event-driven architecture using Kafka topics and consumer groups.
  * Resilient retry and Dead Letter Queue (DLQ) mechanism.
  * Prometheus and Grafana metrics instrumentation.

---

## 🤖 Project 3: AI-Augmented Enterprise System (2028 SDE Differentiator)
* **Tech Stack**: Spring Boot, React, PostgreSQL + pgvector, Redis, Gemini/OpenAI API.
* **Key Features**:
  * End-to-end RAG architecture: document ingestion, chunking, vector embedding generation.
  * Vector similarity search using pgvector.
  * Spring AI / REST tool-calling agents for enterprise domain queries.
  * AI Security: prompt sanitization, sensitive data masking, and output validation guardrails.
